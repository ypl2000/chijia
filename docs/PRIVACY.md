# v3 隐私设计 · 财务数据不出机

本文说明威胁模型、v2 的实际风险点、v3 采取的措施、以及**你可以自己验证的方法**。

---

## 1. 威胁模型

个人财务数据有三个风险面，优先级依次是：

| 面 | 问题 | 常见错误做法 |
|---|---|---|
| **传输** | 数据有没有离开这台机器 | 截图传云视觉模型、pdf.js 从 CDN 加载、埋点上报、把后端绑到 `0.0.0.0` |
| **静态存储** | 落盘内容谁能读 | 明文导出 JSON 随手放网盘、服务端日志留痕、访问日志写磁盘 |
| **展示** | 屏幕/切换时是否泄露 | 离屏不锁、打印/截图无提示、原生弹窗不受主题控制 |

加密只是第二面的一小部分。**关键不是「加不加密」，而是「有没有出机路径」**——出机之后加密也救不回来。

## 2. v2 的四个真实出机口（v3 逐条封堵）

| v2 | 风险 | v3 |
|---|---|---|
| `ai.vision.enabled` 开关 | 一开启，持仓截图上传智谱云 | **端点改为永久 501 `removed_in_v3`**，后端源码里已删除全部外发 URL 与调用代码；配置里也不再有 APIKey 字段 |
| README 建议 `--host 0.0.0.0` + Tailscale | 服务进入局域网 | `serve.py` 与 `backend/app.py` 默认只监听 `127.0.0.1`；多设备需自己走内网隧道，文档不鼓励公网暴露 |
| `core.js` 里 pdf.js 保留 jsdelivr CDN 兜底 | 与「零外部请求」表述矛盾 | pdf.js 3.11.174 已内置 `web/vendor/pdfjs/`，加载失败**不回退 CDN**，直接提示改用粘贴文本 |
| OCR 端点收截图 base64、导出 JSON 明文、SW 缓存无审计 | 图片经过服务端、备份文件可读、不知道发过什么请求 | 见下节 |

## 3. v3 的措施

### 3.1 收口：可核对的零出机

- **统一网络出口审计**：`app.js` 包装 `window.fetch`，记录本会话每一个请求（时间 / 方法 / URL），「设置 → ④ 隐私与安全」直接列出。零后端模式下唯一请求是同源 `GET /api/health`，且静态服务明确返回 `{"ok":false,"mode":"local-only"}`，不会伪装成错误。
- **无第三方资源**：没有 CDN、Web 字体、统计脚本、错误上报。`sw.js` 只拦截同源 GET，`/api/*` 永不缓存。
- **不写访问日志**：`serve.py` 覆写 `log_message` 为空，避免把使用痕迹留在磁盘。
- **后端只托管 `web/` 目录**：`backend/data/`（token、SQLite、config）不在静态根下，不会被 HTTP 读到。
- **失败不静默外发**：PDF 组件本地加载失败就报错提示，绝不偷偷去 CDN 兜底。

### 3.2 静态数据

- 主数据存 `IndexedDB chijia_v3`，`localStorage` 同步镜像（首屏零延迟、`file://` 可用）。
- **口令加密备份**：`PBKDF2-SHA256` 15 万次派生 + `AES-256-GCM`，口令不存储、不发送，导出文件自带 `kdf / cipher / salt / iv`。
- **一键清除**：清 localStorage + 删除 IndexedDB 库，重载后回到示例数据。
- **离屏锁定**：手动锁定按钮；可选「离开页面 2 分钟自动锁定」，锁屏不显示任何财务数字。
- **自定义非阻塞弹窗**替代原生 `alert/confirm`：深浅色下可控，也不会被浏览器当成独立窗口截屏。

### 3.3 识图：不靠更大的模型，靠自校验

v2 的问题是「OCR 出文字 → 关键词锚点猜金额」，识别错了没人知道。v3 改成**结构化抽取 + 会计恒等式校验 + 人工确认**：

1. 截图只 POST 到同源 `/api/portfolio/ocr`，由**本机 RapidOCR** 推理；不落盘、不外发、不进日志。
2. 前端归一成 `名称 / 代码 / 份额 / 成本 / 市值`，做三条恒等式：
   - `市值 ÷ 份额 = 单位净值`，应落在 0.05~100；
   - `市值 ÷ 成本` 应在 0.3~3；
   - `分项市值合计 ≈ 截图总市值`（用户可填，容差 2%）。
3. 每行给置信度与具体问题，可疑行标黄；**多图同名去重**，保留金额较大的一条。
4. **确认表逐格可改、勾选后才写入**。识别率不需要 100%，但错的值过不了校验，也不会静默入库。
5. 原图以 `objectURL` 在模态里对照，关闭即 `revokeObjectURL`。

零后端模式或未装 `rapidocr-onnxruntime` 时给出明确提示，其它功能不受影响。

### 3.4 分析：确定性、可解释、无幻觉

财务结论不适合让生成式模型自由发挥。v3 的「洞察」是**规则引擎**，每条结论都带数值依据和可展开的计算式：

周期性订阅（跨月重复扣款）、疑似涨价、大额异常（均值 + 3σ）、结余率前后半段趋势、实际支出相对计划的偏离、应急垫月数。全部可复现、可审计、不会因为模型版本变化而改动结论。

v2 的 `/api/ai/insight` 一直是 501，等于没有分析能力；v3 用规则引擎补上，且**默认不接任何云端或本机大模型**。

> 如果确实需要自然语言摘要：在自己机器上跑 Ollama（`127.0.0.1:11434`），把已脱敏的聚合数值（不是逐笔流水）发给本地模型，并在 UI 上标注「本机模型生成，未经核对」。这属于自行扩展，v3 不随应用分发、默认关闭。

## 4. 你可以自己验证

```bash
# 1) 源码里不该有任何外部 URL（结果应只有 127.0.0.1 的本机地址）
grep -rn "https\?://" web/js web/*.html web/*.css serve.py backend | grep -v 127.0.0.1

# 2) 云视觉端点已死（应返回 501 removed_in_v3）
curl -X POST -H "X-Auth-Token: <token>" http://127.0.0.1:8410/api/ai/vision

# 3) 断网测试：拔网线/开飞行模式后刷新，六页仍可用、PDF 仍可解析
```

打开「设置 → ④ 隐私与安全 → 网络请求审计」，核对本会话发出的每一个请求。浏览器 DevTools 的 Network 面板也可以看：不应出现任何非 `127.0.0.1` 的域名。

## 5. 已知限制（说清楚比含糊承诺重要）

- 本机 ≠ 绝对安全：浏览器扩展、系统级键盘记录、屏幕截图软件、能物理接触电脑的人，都不在这个应用的防护范围内。
- 导出的明文 JSON 一旦被复制到网盘/聊天工具，就脱离了这套保护；敏感场景请用加密备份。
- 扫描件（图片型 PDF）无法直接解析文字，需改用「粘贴文本」或本地 OCR，代码不会偷偷把文件上传到任何地方。
- 多设备同步时，数据会经过你自己的后端；请保持 `127.0.0.1` + 内网隧道，不要暴露公网，并定期更换 token。
- Service Worker 缓存的是**应用代码**，不是你的数据；清除本机数据会一并删除账本与流水。

## 6. 运维建议

1. 默认用 `python serve.py`（零后端），需要同步时才启动 backend。
2. 每月：导入流水 → 导出一次备份（建议加密）→ 存到离线介质。
3. 换机/大改前先导一份备份；重要操作前在同步面板创建快照。
4. 不要把 `backend/data/token.txt`、`chijia.db` 或备份 JSON 提交到仓库。
