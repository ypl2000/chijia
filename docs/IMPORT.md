# 流水导入：支持的格式与贡献指南

导入器在浏览器本地按行解析流水文本。**贡献新银行格式 = 在 `report.html` 的 `FORMATS` 注册表里加一个 entry**，不需要动其他任何代码。

## 当前内置格式

### `bocom-personal` · 交通银行 · 个人客户交易清单

每行结构（PDF 直接复制或 pdf.js 抽取均可）：

```
序号 日期 时间 交易类型 C/D 金额 余额 对方账号 对方户名 摘要…
```

样例（虚构数据）：

```
1 2025-01-15 12:00:00 跨行汇款 C 15000.00 35000.00 40000560091003 示例科技有限公司 工资
2 2025-02-10 12:00:00 汇款入账 C 600.00 35600.00 40000560091003 示例科技有限公司 Employee Payment
5 2025-04-01 10:00:00 消费 D 6000.00 125600.00 85958404121006 （特约）某商场
```

完整 fixture 见 [`tests/sample-bocom.txt`](../tests/sample-bocom.txt)（6 行，期望全部解析成功；分类：工资 2 笔、奖金 1 笔（金额 ≥ bonusMin）、补贴 1 笔、大额支出 1 笔）。

## 如何贡献新格式

1. 打开你银行流水的 PDF / 网银导出，观察明细行的字段顺序
2. 在 `report.html` 中找到：

```js
const FORMATS = {
  "bocom-personal": { name: "…", re: /…/, map: (m) => ({ d, t, dc, amt, rest }) }
};
```

3. 添加一个新 entry，字段含义固定为：

| 字段 | 含义 | 要求 |
|---|---|---|
| `name` | 展示名 | `"XX银行 · 清单类型"` |
| `re` | 行正则 | 必须产出捕获组：日期(`YYYY-MM-DD`)、交易类型、借贷标志(`C`/`D`)、金额（可含千分位逗号）、户名+摘要（合并进最后一组） |
| `map` | 捕获组 → 标准交易对象 | 返回 `{ d, t, dc, amt, rest }`；`amt` 为数字，`rest` 用于雇主/补贴关键词分类 |

4. 提交 PR：贴 3~5 行**脱敏**样例（人名/账号/金额改成假的，保留格式），说明该格式的获取途径（PDF 全选复制 / 网银导出 CSV…）

解析流程：逐行尝试注册表中的格式，首个命中的即采用——不同格式可以混在同一份文本里。

## 已知限制

- 仅支持"文本可复制"的 PDF（扫描件不行）
- 跨行折行的户名可能截断在行尾（不影响分类的关键词通常在行首）
- 分类规则（雇主关键词、补贴摘要、奖金下限）在页面导入面板里可调，对应 `DATA.meta.importer`
