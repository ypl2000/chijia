# 交互设计规范（A1 架构师 → 实现工程师的硬性要求）

> 版本 v1.0 · 2026-10-25 ｜ 违背本规范 = 验收不通过

## 1. 信息架构（六 Tab，各 Tab 职责互斥）

| Tab | 职责 | 明确不放 |
|---|---|---|
| 🏠 首页 | 引导与入口（四步上手 + 规则 + 直达） | 任何数据表格、任何参数输入 |
| 📋 计划 | 计划推演与预期（④参数面板 + 1.1~1.4 + 预期分布） | 流水导入面板（在设置）、分析统计 |
| 🔎 分析 | 流水统计与健康度（2.x + 3.x） | 计划推演、参数面板 |
| 🧮 计算器 | FIRE 三档模型 | 报告内容 |
| 🧪 体检 | 组合四维红绿灯 | 报告内容 |
| ⚙️ 设置 | 数据操作唯一入口（流水导入/数据包备份/收入口径） | 任何分析结论 |

**红线：任何两个 Tab 不得指向同一视图；任何功能必须在且只在一个 Tab 有入口。**

## 2. 关键任务流

### 流程① 导入流水（设置页）
1. 首页 →「📥 去导入流水」→ 切设置 Tab，导入面板默认展开且可见
2. 选择 PDF（或粘贴文本）→ 点「🔍 解析并预览」→ **必须弹窗或状态行反馈解析结果（含笔数）**
3. 预览确认 → 点「✅ 应用到分析页」→ **必须弹窗确认 + 分析 Tab 数据自动更新**
4. 持久化：会话级 + 「导出备份 JSON」提示

### 流程② 调整计划参数（计划页）
1. 首页 →「🎛 去调参数」→ 切计划 Tab，**参数面板自动展开并滚动到位**
2. 改任意数字 → 点「🔄 按参数重算」→ 1.1~1.4 与预期分布**自动更新且自动展开**
3. 不可行参数（三池 > 可支配）→ 红字警告，不接受静默失败

### 流程③ 财富自由年限（计算器）
1. 调整月收入/月支出/收益率/本金 → 三档年限**实时更新**
2. 报告页「发送」→ 计算器自动填收入/支出/本金（横幅反馈，文字深色可读）

## 3. 组件行为规范

| 组件 | 规范 |
|---|---|
| 折叠面板 | 首页引导与导入面板默认展开；分析各节默认折叠；打印时全部展开 |
| 按钮 | 点击必须有可见反馈（状态变化/弹窗/滚动定位）；危险操作（重置/删除）必须 confirm |
| 空态 | 无数据时显示引导文案（如"填入持仓后自动生成"），不留空白 |
| 错误态 | 解析/导入失败必须弹窗说明原因与下一步，不允许只改小字 |
| 金额 | 千分位；计划页整数、流水页两位小数；带 `≈` 前缀表示估算 |

## 4. 可用性红线

- 触控目标 ≥ 44×44px
- 禁止无反馈交互（点了的元素必须有可见响应）
- 禁止两个导航入口指向同一视图
- 任何弹窗文字与背景对比度必须可读（深色主题下禁止浅底浅字）
