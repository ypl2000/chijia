# 回归测试清单（持家 chijia）

> 每次改版后按此清单过一遍。自动化可测项由 `node tests/audit.js` 覆盖；其余人工/浏览器脚本执行。

## 前置

- 启动：`python serve.py`（上层目录），浏览器打开 `http://127.0.0.1:8931/chijia/index.html`
- 首页可见「构建 v1.x」标记（确认非缓存旧版）
- 清空会话（可选：DevTools → Application → Session storage → Clear），从干净状态开始

## 1. 路由与壳

| # | 步骤 | 期望 |
|---|---|---|
| 1.1 | 打开 index.html | 默认显示「🏠 首页」引导；底部六 Tab |
| 1.2 | 逐个点击六 Tab | 每次高亮切换 + 对应视图显示；切换后状态保留 |
| 1.3 | 首页四步引导按钮 | 分别跳转：设置 / 计划(参数面板展开) / 计划 / 计算器+体检 |
