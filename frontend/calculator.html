调整月收入 / 月支出 / 收益率 / 本金 / 孩数后，三档（轻盈 / 标准 / 富裕）目标本金与年限实时更新。

📐 模型公式与假设

真实收益率（所有折现与复利都用它，今天的钱口径）： rReal = (1 + 长期收益率) ÷ (1 + 个人账单通胀) − 1

档位（递进分层）公式
🪶 轻盈 · 生活池年支出 ÷ rReal
🏡 标准 · 含育儿轻盈 + 孩数 × 每孩育儿折现
🌊 富裕 · 含健康标准 + 健康池原值 + 重大投入折现

育儿折现：每孩现值 = (每孩成本 ÷ 18) × annuity(18, rReal)，其中 annuity(n, rr) = rr ≤ 0 ? n : (1 − (1+rr)^−n) ÷ rr（18 年年金现值系数）—— 育儿成本摊在备孕到 18 岁逐年支出，钱先在组合里增值，故折现后低于名义成本（默认 108 万/孩按 v1 默认参数约折现至 93 万）。

健康池按原值不折现（刻意保守）：医疗通胀长期偏高且波动大，老年支出时点与金额不确定，精确折现反而危险。 重大投入折现：现值 = 金额 ÷ (1 + max(rReal, 0))^年数；rReal ≤ 0 时按原值计入。

个人账单通胀默认 2.33%：按 v1 默认账单构成加权（房租 ≈ CPI+0.5pp、饮食 ≈ CPI−0.5pp、 医疗 ≈ CPI+2.5pp、其他 ≈ CPI；v1 默认月支出 1 万 = 房租 4000 + 饮食 25% + 医疗 10% + 其余，加权 π ≈ 2.325%）。可在参数里直接改。

口径说明 · 永续 vs 提取率（SWR）：本页三档均为「本金不动」的永续口径——投资收益覆盖开销并追上物价， 本金购买力不损耗。「安全提取率（SWR）」则允许本金慢慢花（每年提取固定比例，源自美股百年回测的 4% 法则； 中国市场波动更大，常打折到 3~3.5%）：生活池需求降为「年支出 ÷ 提取率」，数字显著更低，但并非严格意义的永远。 提取率越低越接近永续。

公式失效边界：当长期收益率 ≤ 个人账单通胀时 rReal ≤ 0，「本金不动」口径分母 ≤ 0， 在数学上不可能实现（日本过去三十年的教训）——页面会明确提示，此时仅「提取率（SWR）」口径可行。

数据来源：每孩成本 108 万默认值取《中国生育成本报告》上海口径（备孕至 18 岁平均）； 通胀锚点为长期经验值，可按最新数据自行调整参数。

三档为递进分层口径：轻盈=只算日常生活，标准=含育儿，富裕=再含健康池与重大投入；目标口径为「本金不动（永续）」。示例模型，非投资建议。计划页参数变化会持续同步到本页（FFC_PREFILL）。
